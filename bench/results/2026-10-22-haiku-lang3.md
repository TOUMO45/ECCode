# Benchmark run — 2026-10-22, claude -p (haiku), Go + Python tasks, n=5 per variant

> **Follow-up.** Every task in this file was later run at n≥10 per variant ([2026-10-23-haiku-n10-remaining.md](2026-10-23-haiku-n10-remaining.md), [2026-10-23-haiku-n10-replication.md](2026-10-23-haiku-n10-replication.md)), and the two headline tasks at a fixed-protocol n=25 ([2026-10-23-haiku-n25-preregistered.md](2026-10-23-haiku-n25-preregistered.md)). This file's runs stay in the record and in the all-data stratified test (`eccode bench tally`); its small-n figures are not the basis of any conclusion.

Third-language extension of the paired benchmark: `go-clamp` (Go, hidden `go test`
checks copied in after the agent run) and `py-kebab` (Python, hidden `pytest`
checks). Same protocol as the earlier runs: paired with/without the lean-change
skill text, hidden checks never present while the agent works, exact permutation
test on lines added (difference of means, all 252 splits of 5+5).

**What this run shows.** The discipline holds outside JavaScript: 20/20 runs
passed every hidden check, 0/20 added a dependency, and 20/20 changed or added a
test file — in both variants. That last column is the honest headline: on these
two tasks the baseline agent already writes tests unprompted, so the lean skill
has little left to buy. The diff-size deltas (−3 median lines on go-clamp,
−1 on py-kebab) are small and not significant (p=0.341 and p=0.167). The skill
costs ~7–9 median seconds of reading time.

**What it does not show.** No effect worth claiming on diff size for small Go and
Python tasks where the baseline behaves well. The significant effects measured
earlier (p=0.0079–0.0159 on relative-time, slugify-reuse, dedupe-objects) came
from tasks where the unskilled baseline skipped tests or duplicated existing
helpers; where the baseline is already disciplined, the skill is close to a
no-op — which is the designed behavior, not a win.

# ECCode paired benchmark

Agent command: `cat PROMPT.md | claude -p --model haiku --allowedTools "Read Grep Glob Edit Write Bash(npm test) Bash(node --test*) Bash(pytest*) Bash(go test*)"`. "with" prepends the lean-change skill text to the prompt; "without" is the bare prompt. Hidden checks never exist in the sandbox while the agent works. Small n means a demonstration, not a statistic — read the raw rows, not just the medians.

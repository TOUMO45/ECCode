**Outcome (the pre-registered primary analysis): on Sonnet the lean-change skill makes diffs larger, not smaller.** Stratified permutation test over this batch, both halves (labels shuffled within each task; 8 strata, 160 runs; `eccode bench tally --dir` over the two files): with − without = **+3.00 lines per change in the pre-registered Sonnet batch**, two-sided p = 1.0e-4 over 20,000 seeded resamples. Per task (exact permutation on lines added; the report prints p<0.0005 as 0.000): larger with the skill on csv-sum (+5, p = 2.2e-5), go-clamp (+16, p = 7.1e-4), dedupe-objects (+7.5, p = 0.053) and relative-time (+9, p = 0.40); smaller on fix-last-page (−6, p = 1.0e-3); equal medians on py-kebab (p = 0.087), py-page-id and slugify-reuse (p = 1).

**Secondary outcomes (pre-registered).** Hidden checks 320/320; 0 dependency additions; 0 agent failures. Runs that changed a test file: **80/80 with the skill, 45/80 without** (without: csv-sum 0/10, go-clamp 2/10, dedupe-objects 3/10, relative-time 4/10, py-kebab 6/10, the other three 10/10).

**Exploratory, not pre-registered, and not causal.** The skill tells the agent to add a focused test for new non-trivial logic, and lines added counts test lines too. Splitting each variant's runs by whether they changed a test file (from the raw rows below): among runs that did, the with-skill diff was smaller or equal on every task where both variants have such runs (median lines with vs without: dedupe-objects 16 vs 21, go-clamp 25 vs 27, relative-time 28 vs 37.5, fix-last-page 8 vs 14; py-kebab, py-page-id and slugify-reuse equal; csv-sum has no bare run with a test). Bare Sonnet's diffs were smaller only in the runs where it shipped no test. This conditions on an outcome the skill itself changes, so it suggests, but does not show, that the growth is the tests. These reports do not record test lines separately, and the protocol's stopping rule forbids re-sampling Sonnet on these tasks to find out; since this batch the harness records lines added in test files per run, so a future batch answers it directly.

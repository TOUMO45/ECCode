# Impact analysis at scale: the Python standard library

Date: 2026-10-23. Corpus: the Python 3.13 standard library as installed by the distribution (`/usr/lib/python3.13`, without `__pycache__`, `site-packages` and compiled extensions): 589 indexed Python files, 280,766 lines. The distribution ships the test infrastructure (`test/support`, `test/libregrtest`) and few test modules, which makes it a hard case for telling tests from test support.

Two layouts of the same files, each committed to a scratch git repository:

- **flat**: the library at the repository root (`os.py`, `asyncio/`, `test/`).
- **Lib/**: the CPython checkout layout (`Lib/os.py`, `Lib/asyncio/`, `Lib/test/`), plus one script under `Tools/scripts/`.

Query: `eccode impact os.py --json` (flat) and `eccode impact Lib/os.py --json` (Lib/), with `--refresh`, run by the engine before this change (commit 90ef4e7) and after it.

| Layout | Engine | Dependents of os.py | Affected tests | Test support listed apart | Modules | First modules listed |
|---|---|---|---|---|---|---|
| flat | before | 361 | 44 | — | 164 | `_aix_support.py`, `_android_support.py`, `_apple_support.py` (alphabetical) |
| flat | after | 361 | 2 | 42 | 164 | `asyncio` (30), `email` (27), `multiprocessing` (23) |
| Lib/ | before | 127 | 0 | — | 1 | `Lib` |
| Lib/ | after | 360 | 2 | 42 | 163 | `Lib/asyncio` (30), `Lib/email` (27), `Lib/multiprocessing` (23) |

What changed, and why each row moved:

1. **Absolute Python imports resolve from the file's import root.** A file's import root is its nearest ancestor directory that is not a package (no `__init__.py`), as on `sys.path`. Before, only the repository root, `src/` and the file's own directory were tried, so in the `Lib/` layout `import os` from `Lib/asyncio/events.py` resolved to nothing: 233 of the 360 dependents were invisible.
2. **Affected tests are runnable tests only.** A file under a test path counts when its name follows the runner's convention, or it defines tests and the runner would collect it (pytest and unittest collect only `test*.py`; `go test` only `*_test.go`). Helpers, fixtures, runners and `conftest.py` are listed as test support. Before, the 44 "affected tests" were 42 support files (`test/support/*`, `test/libregrtest/*`) plus 2 test modules. `test/libregrtest/testresult.py` stays a test: it defines `TestCase` methods that unittest discovery collects.
3. **Modules mean something in both layouts.** A directory that holds most of the code and several code subdirectories (`Lib/`, a large `src/`) is opened one level, so its children are the modules. Modules are listed largest first with their file counts.
4. **Dependents are ranked.** Nearest first; at each distance, the files that most other files depend on come first (`threading.py`: 46, `contextlib.py`: 41, `subprocess.py`: 32), so the files a reviewer should open first lead the list.

The index of the 589 files is built in about 0.6 s (cached afterwards).

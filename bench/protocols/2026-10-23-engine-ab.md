# Pre-registered protocol: does the full engine change outcomes, and at what cost?

Committed and pushed before any run of this batch starts; the git commit timestamp is the registration.

**Why.** Every recorded benchmark so far (622 runs) compares an agent with and without the lean-change skill text in its prompt. The engine itself has never been in the loop: no run has had its gates, independent review, evidence rules and record. This batch compares an agent working alone with the same agent delivering through the engine's quick track, on multi-file tasks with regression traps, and measures what the engine costs.

**Design (fixed in advance).**
- Suite: `bench/suites/engine`: search-case and extract-pricing (JavaScript), stock-reorder and utc-month (Python). Each task has a trap a careless change falls into (a shared helper with a case-sensitive caller, a public export the refactor must keep, a positional CSV consumer, a root-cause bug with two consumers). `tests/bench.test.js` proves each trap is real: a careless reference passes the visible tests and fails a hidden regression check, and a good reference passes every check. No model has run these tasks except the pilot below.
- Variants: `without` (the bare task prompt) and `engine` (the toolkit installed in the sandbox with the `guard` profile and committed before the agent starts; the prompt asks for delivery through `.claude/commands/eccode/quick.md`; every subagent inherits the session's model, so the process is compared, not a model mix).
- Models: two batches, one per model alias, `sonnet` and `opus`. Agent command, identical for both variants except the model:
  `cat PROMPT.md | claude -p --model <model> --output-format json --allowedTools "Read Grep Glob Edit Write Agent Task Bash(npm test) Bash(node --test*) Bash(pytest*) Bash(node .claude/eccode/bin/eccode.js*) Bash(git diff*) Bash(git status*)"`
- n = 5 per variant per task per model: 40 runs per model, 80 in all. Timeout 2,400 s per run. The two models run in parallel, each as one `eccode bench --suite bench/suites/engine --variant without,engine --runs 5 --timeout 2400` process.
- **Primary outcome: a run passes when it passes every hidden check** (feature, regression or root cause, and no new dependency).
- **Primary analysis, per model:** the difference in pass rate, engine minus without, tested with the permutation test stratified by task (labels shuffled within each task; 20,000 seeded resamples; two-sided), as printed in the report's "all tasks" row and by `eccode bench tally --dir bench/engine-results`.
- Secondary outcomes: which hidden checks failed, per variant; cost and tokens per run as the agent reported them for the whole session (subagents included), medians and the engine/without ratio; wall time; the engine record (delivered, audit OK, review rounds, changes requested); lines added and tests written; per-task Fisher exact tests.
- **Decision rules, per model:**
  - difference > 0 and p < 0.05: the engine improved correctness on these tasks for this model.
  - difference < 0 and p < 0.05: the engine made correctness worse; a register row opens as a defect.
  - otherwise: no measured correctness difference at n = 5 per cell, which does not show the effect is zero. The cost ratio is then the headline result.
  - Whatever the pass rates show, the median cost ratio (engine/without) is reported per model.
  - Any engine run whose record fails its audit opens a register row as a defect.
- Reporting: both reports are committed verbatim as `bench/engine-results/2026-10-23-engine-sonnet.md` and `-opus.md`, whatever they show, with this protocol cited. A run that fails for an infrastructure reason (API error, timeout) stays in the raw rows as it is; nothing is re-run or dropped.
- Stopping rule: one batch per model. No further sampling of these four tasks with these two models after it.

**Pilot, disclosed and excluded.** Before this protocol, one pilot validated the harness end to end: search-case, one run per variant, `sonnet`. Without: 3/3 hidden checks, 271,609 tokens, $0.11, 16 s. Engine: 3/3 hidden checks, delivered, audit OK, 2 reviews, 1,583,949 tokens, $0.54, 127 s. The pilot is not part of the analysis.

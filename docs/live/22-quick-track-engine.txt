# The one-step path, live: a headless session delivers through the quick track with real subagents

The engine-benchmark pilot (bench/protocols/2026-10-23-engine-ab.md, disclosed there and excluded from the analysis): one `claude -p --model sonnet --output-format json` session in a sandbox with the toolkit installed (guard profile, every subagent on the session's model), task search-case from bench/suites/engine. The harness did not save the agent's final answer; this file is the prompt and the record the session left, read back with the commands shown. Hidden checks afterwards: 3/3 (feature, regression, no new dependency). The session reported 1,583,949 tokens (cache reads included) and $0.54 over 127 s; the bare run of the same task took 271,609 tokens, $0.11 and 16 s, and also passed 3/3.

## Prompt (PROMPT.md, written by the harness)

This repository has the ECCode toolkit installed under .claude/. Deliver the change below through its quick track:
follow .claude/commands/eccode/quick.md step by step, with `node .claude/eccode/bin/eccode.js` as the CLI and the ECCode
subagents it names. The change is done when the delivery step succeeds.

The change:
Search should ignore case: searching 'ada lovelace' must find a profile named 'Ada Lovelace', and so must 'LOVELACE'. Results stay the same handles, in the same order. Tests run with: npm test

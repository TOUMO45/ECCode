## Verdicts and fixes

- **`app/tally.py:1` mutable default (B006, mutable-default):** Real. The shared default list makes `add('a')` followed by `add('b')` return `['a', 'b']`. Fixed with `bucket=None` and a new list created inside the function when it is `None`.
- **`app/tally.py:7` `count is 1` (F632, is-literal):** Real. `is` compares identity and only works here because CPython caches small integers. Fixed by returning `count == 1`, which also clears the SIM103 warning on the same line.
- **`src/report.js:4` `total === NaN` (nan-compare):** Real. The guard can never fire, so an empty `rows` array returns `NaN` instead of `0`. Fixed with `Number.isNaN(total)`.
- **`src/report.js:5` async `forEach` (async-foreach):** Real. `summarize` returned before the saves finished, and save errors were lost. Fixed by making `summarize` async and using `for (const r of rows) await save(r);`. This changes the return type to a Promise, so any synchronous caller of `summarize` would now break. I only checked the three changed files for callers and found none, so that check is still open for the rest of the repo.
- **`src/report.js:6` `debugger`:** Real. Removed the leftover statement.
- **`src/report.js:10` `'strng'` typo (typeof-typo):** Real. The string passthrough branch could never run. Fixed the literal to `'string'`.
- **`tests/report.test.js:4` `test.only` (focused-test):** Real as a latent bug. Any test added later to the file would be silently skipped. Changed `test.only(` to `test(`.
